# 💰 Pricing Page (Tarification)

##  Description
This project is a responsive pricing page (Tarification) developed using HTML, CSS, and Bootstrap.  
It displays different subscription plans for a web application, including Free, Pro, and Enterprise offers.

---

##  Technologies Used
- HTML5  
- CSS3  
- Bootstrap 5  

---

##  Features
- Responsive navigation bar  
- Search bar functionality (UI only)  
- Pricing section with 3 plans  
- Clean and modern card design  
- Responsive layout for all devices  
- Buttons for each subscription plan  

---

##  Preview
This page includes:
- Free plan (0$ / month)
- Pro plan (15$ / month)
- Enterprise plan (29$ / month)

---

##  How to Run
1. Download or clone the repository  
2. Open the project folder  
3. Open `index.html` in your browser
